# Add background to inline/block code and hide raw backticks in Note

<!-- Please only use this template for submitting common issues -->

### Description:
I would like to suggest a visual improvement for the rendering of `inline code` and
```
code blocks.
```

Additional Issue:
There is also a minor rendering issue with inline code. When wrapping text in backticks (e.g., `code`), the backticks themselves remain visible in the rendered output. They should ideally be hidden once the markdown is parsed.

### Why:
Currently, when formatting text as code, only the text style changes. It lacks a background color, making it somewhat difficult to distinguish the exact boundaries of the code elements from regular text. It would be great to add a background color to these elements so their areas are easily recognizable. For dark mode, the background rectangle should be slightly lighter to provide proper contrast.
