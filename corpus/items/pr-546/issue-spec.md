# Add 'Created' date attribute for document sorting

<!-- Please only use this template for submitting common issues -->

### Description:
Currently, the document list only supports sorting by the `Modified` attribute, as seen in the current UI. This issue proposes adding a `Created` date attribute so that users can also sort their documents based on the original creation date.

<img width="1470" height="417" alt="Image" src="https://github.com/user-attachments/assets/4efb887e-a778-4370-a705-54972e142f9a" />

### Why:
Relying solely on the modified date makes it difficult to locate specific documents when users only remember when they were originally made, especially if they have been edited multiple times since. Adding a sorting option based on the created date will significantly improve file discoverability and provide a more flexible and intuitive document management experience for users.
